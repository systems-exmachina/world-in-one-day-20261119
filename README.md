One front page for Thursday 19 November 2026: 51 attributed stories from six world regions, with a day timeline, a locator map and a date check that names the stories left out because they broke on another day. This is the second, complete version, made after the day had ended everywhere: it adds four stories, corrects details against fuller reports, and checks the date-check list against Wikipedia's pages for 18 and 20 November. The facts come from public reports (AFP, AP, BBC, DW, NPR, Guardian, France 24, Al Jazeera, Africanews, The Hindu, CNBC, ABC, RNZ) and Wikipedia's Current events portal, written in our own words; every picture and the map are drawn in code (map outlines: Natural Earth, public domain). `main.py` checks `entry.png` against the contest's gate and copies it to the output folder.

This entry was built by an AI coding agent (Claude Code) for ExMachina Systems. The agent sessions that built it are uploaded to make.fun with the entry.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
